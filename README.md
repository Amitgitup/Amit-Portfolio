# 🚀 Amit Singh | AI Engineer & Software Developer Portfolio

A modern, highly interactive 3D developer portfolio showcasing expertise in **Agentic AI**, **Large Language Models (LLMs)**, **RAG Systems**, **Machine Learning**, and **Cloud Infrastructure**. Built with **React 18**, **Three.js**, **React Three Fiber**, **Rapier Physics**, and **GSAP ScrollSmoother**.

---

## 🛠️ Tech Stack

- **Core Frameworks:** React 18, TypeScript, Vite
- **3D Graphics & Physics:** Three.js, @react-three/fiber, @react-three/drei, @react-three/rapier (RigidBody 3D physics)
- **Animations & Effects:** GSAP 3 (ScrollSmoother, ScrollTrigger, SplitText)
- **Styling:** Modular CSS3 with responsive typography and theme variables
- **Deployment:** Vercel

## 📂 Project Structure

```text
├── public/                 # Static assets
│   ├── draco/              # Draco compression decoder libraries for 3D models

│   │   └── Contact.tsx     # Direct contact info, education, and social links

│   └── index.css           # Global CSS variables, typography and base styles
├── package.json            # Scripts and dependencies
├── vite.config.ts          # Vite build configuration
└── tsconfig.json           # TypeScript configuration
```

## ⚡ Getting Started Locally

### 1. Clone the Repository
```bash
git clone https://github.com/Amitgitup/Portfolio.git
cd Portfolio
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run the Development Server
```bash
npm run dev
```
The site will run at `http://localhost:5173`.

### 4. Build for Production
```bash
npm run build
```
